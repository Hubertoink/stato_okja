Ohne eigene IT

Betreut nutzen

Eine Adresse und ein Zugang für euer Team. Der vereinbarte Betreiber kümmert sich um Installation, Updates und Sicherungen.

Betreuten Zugang anfragen

Verfügbarkeit, Kosten und Zuständigkeit werden vor der Bereitstellung vereinbart. Die Anfrage erstellt noch kein Konto.

Mit eigener IT

Eigener Server

StatO auf eurer Infrastruktur betreiben. Ein Release-Installer übernimmt die Einrichtung; eure IT betreut den laufenden Betrieb.

Installationsanleitung öffnen

Docker und Docker Compose werden benötigt. Der Server braucht keinen Quellcode und kein Node.js.

NAS oder Portainer vorhanden

Datei importieren

Adresse und Port eintragen, eine fertige Konfiguration herunterladen und als App oder Stack importieren.

Konfiguration erstellen

Eure zuständige Person übernimmt HTTPS, Updates und die Sicherung auf einem zweiten Speicher.

Nach dem ersten Start

Einrichtungscode eingeben, Adminzugang festlegen, Organisation anlegen und Teammitglied hinzufügen. Ohne Mailserver funktioniert die lokale Benutzeranlage.
