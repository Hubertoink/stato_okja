Mit StatO verbinden

Verbinde diese App mit dem StatO-Server deiner Einrichtung oder deinem gehosteten Zugang.

Vollständige Adresse mit https:// und optionalem Port. Auch interne Domains und IP-Adressen sind möglich.

HTTP verschlüsselt die Verbindung nicht. Für Anmeldung und Daten bitte HTTPS auf dem Server einrichten.

Die Serveradresse wird auf diesem Gerät gespeichert. Deine Anmeldung erfolgt anschließend direkt bei StatO.

Für einen internen Server brauchst du Zugang zum Einrichtungsnetz oder eine VPN-Verbindung.
